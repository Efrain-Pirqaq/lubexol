# SEO/GEO técnico

- HTML rastreable y contenido principal visible sin depender de interacción.
- Títulos y descripciones únicos y descriptivos.
- Canonical correcto, sitemap XML y robots.txt revisados.
- URLs estables, breadcrumbs cuando aporten.
- Imágenes optimizadas y alt descriptivo.
- Enlaces internos útiles entre artículos, episodios y productos.
- Schema solo cuando corresponda al contenido visible (por ejemplo Article/BlogPosting, Product si cumple requisitos, BreadcrumbList, PodcastEpisode si el vocabulario/soporte aplicable está validado).
- No añadir marcado engañoso ni datos que no aparecen en la página.
- Revisar Search Console y errores de indexación después de publicar.
- No prometer indexación ni posiciones.
