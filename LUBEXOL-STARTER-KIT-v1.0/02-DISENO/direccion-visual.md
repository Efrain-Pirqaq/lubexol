# Dirección visual

## Propuesta
Estilo `Industrial Premium`: profesional, claro, confiable y orientado a comparar productos rápidamente.

- Paleta propuesta: azul petróleo como color principal, neutros claros y acentos moderados.
- Tarjetas de producto limpias, fotografía legible, marca/modelo/viscosidad y presentación claramente diferenciadas.
- Priorizar legibilidad, jerarquía y acciones visibles; evitar estética recargada.
- Marca confirmada: Lubexol (LUBEXOL), a utilizar en encabezado y elementos oficiales de identidad.
- No inventar logotipos, certificaciones, sellos ni testimonios.

## Entregable visual previo a programar
Wireframes de escritorio y móvil, estados vacíos, carga, error, selección y resumen de cotización. Usuario debe aprobarlos.
