# Adaptadores e independencia de proveedores

Adaptadores potenciales:
- Persistencia: Sheets, SQL u otro proveedor.
- Archivos: Cloudflare R2 u object storage compatible.
- Hosting/ejecución: Cloudflare u otro proveedor.
- Email: Resend u otro proveedor.
- Analítica: GA4 u otra solución.
- Podcast hosting/RSS: plataforma especializada o solución propia.

No asumir que todas estas herramientas serán elegidas. Evaluar primero requisitos y coste. Mantener exportación de datos y un procedimiento de sustitución.
