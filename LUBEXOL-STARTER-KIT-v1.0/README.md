# LUBEXOL — Paquete maestro de construcción v1.0

Este paquete contiene la especificación inicial para construir el sitio comercial de lubricantes y sus módulos de blog y podcast, bajo un enfoque Starter Kit reutilizable.

## Cómo empezar
1. Descomprime la carpeta dentro de tu entorno de trabajo.
2. Abre la carpeta raíz con Antigravity.
3. Pide que lea primero `00-MAESTRO/INSTRUCCIONES-ANTIGRAVITY.md` y todos los documentos referenciados.
4. Antes de modificar o crear código, debe producir un diagnóstico del repositorio y una matriz de cumplimiento.
5. No autorices implementación hasta revisar las decisiones pendientes de `00-MAESTRO/CONTROL-DE-DECISIONES.md`.

## Estado del paquete
Este es un paquete de especificación y planificación para iniciar la construcción; **no es código de aplicación ni confirma que las integraciones estén configuradas**. Las decisiones no confirmadas están marcadas como `PENDIENTE`. No deben convertirse en supuestos.

## Principios obligatorios
- No programar funcionalidades no especificadas.
- No inventar datos comerciales, precios, disponibilidad, compatibilidad de productos ni credenciales.
- Separar núcleo reutilizable, módulos funcionales, adaptadores e implementación específica de Lubexol.
- Mantener blog y podcast desacoplados del catálogo.
- Una selección o clic de WhatsApp no equivale a una venta.
- Toda etapa requiere pruebas y aprobación antes de avanzar.
