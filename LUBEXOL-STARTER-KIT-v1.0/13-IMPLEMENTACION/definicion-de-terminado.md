# Definition of Done

Una tarea está terminada solo si:
1. Cumple el requisito documentado.
2. No rompe módulos existentes.
3. Tiene pruebas apropiadas y estas pasan.
4. Maneja estados de error y vacío.
5. Respeta accesibilidad y responsive.
6. No introduce secretos ni datos inventados.
7. La documentación y decisiones se actualizan.
8. Se presenta evidencia verificable al usuario.
9. El usuario aprueba cuando la tarea forma parte de una fase con aprobación requerida.
